# Smart Agri 🌱

## Overview

**Smart Agri** is a full-stack web application developed to simplify and modernize the agricultural selling process by enabling farmers to sell their crops directly to **JD Solution**. The platform aims to eliminate unnecessary intermediaries, provide fair pricing, and improve transparency through a user-friendly digital experience.

Designed with accessibility in mind, Smart Agri supports **Marathi, Hindi, and English**, making it easy for farmers from different regions to use the platform. The application features **OTP-based authentication** for secure login, a personalized dashboard displaying **real-time crop price comparisons**, **weather forecasts**, and a **Smart Advice** system that provides useful recommendations based on weather conditions and crop information.

Farmers can submit crop selling requests, monitor their request status from submission to completion, manage their profiles, and access a dedicated support section for assistance. The responsive interface ensures a seamless experience across desktop and mobile devices.

The project follows a modern full-stack architecture with a **React** frontend styled using **Tailwind CSS**, while the backend is built with **Node.js**, **Express.js**, and **MongoDB** for efficient data management and API handling.

Smart Agri demonstrates the practical application of full-stack web development by integrating secure authentication, database management, multilingual support, responsive UI design, and real-world agricultural workflows into a single platform. The project showcases skills in frontend and backend development, REST API integration, database design, and building scalable, user-centric web applications.
